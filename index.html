Terms & Security Architecture Statement

• Data Isolation & Encryption: All transactions, debt ledgers, and personal expense logs are processed through encrypted HTTPS SSL protocols connected to Supabase PostgreSQL infrastructure.

• Access Privileges: Standard user accounts possess read-only ledger filtering privileges restricted exclusively to their designated account parameters. Master administrative configuration remains restricted to the authenticated Admin profile.
